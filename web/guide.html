拾刻使用和运行说明

首次设置

本机使用 python -m shike serve --open 启动，会自动打开专属设置入口，直接设置管理密码。已启动时可运行 python -m shike open。

Docker 可运行 docker compose exec shike python -m shike setup-link，打开命令提供的初始化链接。首次初始化完成后，日常只需输入管理密码。

接入 Telegram

  1. 在 my.telegram.org/apps 创建应用，获得 API ID 和 API Hash。
  2. 在设置中配置连接信息。若服务器不能直连，可保存代理后测试连接。
  3. 添加账号，点击生成二维码，在手机 Telegram 的“设置 → 设备 → 连接桌面设备”中扫描。
  4. 账号开启两步验证时，继续输入该密码；也可使用手机号验证码或导入已有会话。

验证码和两步验证密码不落盘，登录会话在服务器加密保存。二维码和会话都是登录凭证，只在自己的实例操作。

安排任务

先选择执行账号，再选择目标会话。按顺序添加发送、等待回复、点击按钮步骤，最后选择时间和时区。

保存计划不会立即发送。立即执行时，页面会先显示真实发送内容供你确认。群提醒可以只发送消息，不必等待回复。

读懂执行结果

“已收到回复”仅表示目标返回消息，不推断签到是否成功。只有配置的关键词命中，才进一步显示业务判定。

消息已经发送但等待超时，或者显示“发送结果未确认”时，请先查看 Telegram 会话。不要直接重复执行。服务不会在重启后自动重发不确定的操作。

保持运行与维护

关闭浏览器不影响任务。部署服务必须保持运行，错过的历史计划默认跳过，恢复后继续后续计划。同一数据目录只运行一个服务进程。

备份应停止服务后复制完整数据目录，同时保留数据库和加密密钥。Docker 升级保留原数据卷，不要执行带 -v 的删除卷命令。

忘记管理密码时，实例所有者可停止服务并运行 python -m shike reset-password。
